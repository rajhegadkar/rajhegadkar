## 🏗️ Flagship Infrastructure Projects

### 1. 🛡️ [Self-Hosted Remote Access Gateway](https://github.com/YOUR_GITHUB_USERNAME/portfolio#projects)
> **Linux / Ubuntu Server • Apache Reverse Proxy • Cloudflare Tunnel • Windows RDP • Linux SSH**

- **Challenge**: Provide secure, authenticated remote access for corporate administrators without exposing external firewall ports or paying exorbitant proprietary VPN license fees.
- **Solution**: Deployed an outbound-only encrypted tunnel utilizing **Cloudflare Tunnel (`cloudflared`)** tied to an **Apache reverse proxy** on Ubuntu.
- **Result**: Zero exposed inbound ports, end-to-end TLS encryption, unified gateway for Windows RDP and Linux SSH, and reduced exposure surface.

```text
  [ External User (Internet) ]
               │ (HTTPS / TLS)
               ▼
  [ Cloudflare Tunnel ]  <── Zero Inbound Ports Open to Public
               │ (Encrypted Tunnel)
               ▼
  [ Linux Gateway (Apache Reverse Proxy) ]
         │                        │
         ▼                        ▼
  [ Windows Server ]       [ Linux Nodes ]
     (RDP : 3389)             (SSH : 22)
```
